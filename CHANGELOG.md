# Changelog

NVSentinel's changelog is published as part of each [GitHub Release](https://github.com/NVIDIA/NVSentinel/releases), alongside `versions.txt` listing the exact component versions included.

For a narrative summary of major releases, see the release notes files in this repository (e.g. [RELEASE_NOTES_v1.0.0.md](RELEASE_NOTES_v1.0.0.md)).

See [RELEASE.md](RELEASE.md) for how releases are cut.
