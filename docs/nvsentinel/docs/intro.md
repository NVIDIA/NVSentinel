# Intro

Let's discover **NVSentinel**.

## Getting Started

NVSentinel is a cross-platform service that rapidly detects runtime node-level faults in accelerated computing environments, allowing stakeholders and automation to make informed decisions and promptly respond to workload failures or performance degradation. 

## Goals
1. Monitor hardware events, including errors and warnings reported by hardware drivers through various channels, such as device utilities and kernel logging.
    - The monitored hardware components include DGX subsystems such as GPUs, NVSwitches, NVLink, PCIe, IB Ports, etc. 
2. By thoughtfully extending interfaces in the cloud native space rather than creating solutions tailored to specific use cases, we can provide a streamlined and minimalistic abstraction.
